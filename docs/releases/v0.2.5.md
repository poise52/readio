## What's new

- Read EPUB, FB2 and TXT books aloud using OpenRouter TTS models, online Edge voices, or a separately installed local Piper engine and voice model.
- Browse and refresh the OpenRouter model catalog, search by name or ID, filter free and paid models, and choose available voices.
- Use the compact player to adjust speed and volume during playback. Customize the accent color with presets, a color picker, or RGB and hex fields.
- Download narrated books for offline listening. Resume interrupted downloads, retain playback position, and keep the voice, model and dictionary selected for each saved edition.
- Review an estimate before downloading and set limits on new requests and spending. Reconcile reported costs for previous OpenRouter attempts without generating audio again. Estimates are not actual charges; some costs remain unknown until reported by the provider.
- Navigate and highlight text using supported Edge timing data; navigation is approximate when suitable timing data is unavailable.
- Import more text encodings, including UTF-16 with BOM and declared Windows-1251 XML. Batch imports now avoid partial results on error.

## Reliability and protection

- Generation attempts are recorded before requests are sent. Cached audio is reused where possible, and retries after an uncertain result require confirmation because a repeated request may be charged again.
- Offline editions retain their saved block plan, and damaged manifests can be restored from a checked JSON backup. Back up the complete application data directory to preserve plans and audio as well.
- Shared requests are deduplicated, submitted audio is saved during shutdown, and a single data directory is protected from simultaneous use by multiple Readio processes.
- OpenRouter API keys are stored in the system credential store.

## Downloads and requirements

Download the Windows 11 x64 NSIS installer or the macOS Apple Silicon build from the assets below. The Windows installer is unsigned; the macOS build is ad-hoc signed and not notarized, so the operating system may require an explicit first-run approval.

OpenRouter and Edge require an internet connection for generation. OpenRouter model availability and pricing depend on the provider and account. Piper requires a separate installation and an ONNX voice model with its configuration. Previously downloaded audio can be played offline.
