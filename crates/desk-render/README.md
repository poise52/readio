# Озвучивание

Edge использует онлайн-сервис Microsoft; при ошибке автоматически выбирается первая доступная модель Piper. Идентификатор выбранного голоса Piper возвращает `voices()`.

Для офлайн-озвучивания установите **нативный C++ Piper CLI** из [релизов rhasspy/piper](https://github.com/rhasspy/piper/releases), включая `espeak-ng-data` и библиотеки рядом с исполняемым файлом. Поддерживаются параметры `--model`, `--output_raw` и `--length_scale`. Современный Python CLI проекта [OHF-Voice/piper1-gpl](https://github.com/OHF-Voice/piper1-gpl) не проверен и не входит в поставку; Python для приложения не требуется.

Приложение ищет бинарник в `<data_dir>/piper/piper` (`piper.exe` в Windows), затем в `PATH`. Переменная `READIO_PIPER_BIN` задаёт полный путь. Модели ищутся в `<data_dir>/models/piper` или в каталоге `READIO_PIPER_MODELS` на глубину до двух вложенных каталогов. Нужны файлы `ru_RU-*.onnx` и `ru_RU-*.onnx.json`; JSON должен содержать `audio.sample_rate`. Модели совместимы с Piper CLI; модели sherpa-onnx из старого приложения могут иметь другой формат и не подходят автоматически.

Один запрос ограничен 8000 байтами UTF-8. Клиент разбивает длинный текст на фрагменты. WAV строится из 16-битного моно PCM; вывод ограничен 32 МиБ. Остановка отменяет запрос и завершает процесс Piper.

Сетевой smoke test: `cargo test -p readio-speech edge_network_smoke -- --ignored --nocapture`.

`vendor/msedge-tts` содержит исходный код msedge-tts 0.4.1 (MIT/Apache-2.0) с локальным исправлением: закрытие WebSocket или EOF до `turn.end` считается ошибкой, заголовок бинарного аудиокадра проверяется перед чтением. Сохранён только набор зависимостей Tokio. При обновлении библиотеки эти исправления и тесты протокола нужно проверить повторно.

## OpenRouter

Каталог моделей загружается из OpenRouter; он содержит модели с текстовым входом, речевым выходом и `/api/v1/audio/speech`. Без ключа используется публичный каталог, с ключом — каталог `/api/v1/models/user`, учитывающий настройки аккаунта. У моделей показаны цены в исходном виде API; отсутствие цены не считается нулевой стоимостью. Модель и голос выбираются пользователем. Если список голосов отсутствует, поле `voice` может быть опущено или заполнено идентификатором поставщика; поддержку конкретного голоса определяет сервис.

Для Gemini TTS и HeyGen запрашивается PCM, для остальных моделей — MP3. Моно PCM преобразуется в WAV с частотой из ответа; для Gemini и HeyGen, если частота не указана, применяются документированные частоты 24 кГц и 44,1 кГц. Если параметры неизвестны, приложение возвращает ошибку. Скорость устанавливается при воспроизведении.

Нужен ключ OpenRouter. Приложение не переключает модель автоматически и не повторяет запросы после лимита; при `Retry-After` показывает указанное время ожидания. Сервис и цены могут меняться; фактические возможности модели и доступность зависят от аккаунта.
